# 対象機器に合わせて、ルールと設定の項目を変える

embedded-debug-loop の、クロスコンパイル、デプロイ、ログ追加のルールは、対象の機器に合わせて書き換えられます（K-07、K-16）。ルールは、プラグインの中のスキル（`skills/cross-compile-rules/SKILL.md`、`skills/deploy-rules/SKILL.md`、`skills/log-insertion-rules/SKILL.md`）にあります。

## 1. plugin-creator に作り直しを頼む（設定の項目も変えるとき）

設定画面の項目も変えるときは、plugin-creator の作り直し（既存プラグインの設計変更）を使います。

1. plugin-creator に、「このフォルダのプラグインを作り直したい」と頼みます。
2. embedded-debug-loop のフォルダを示します。
3. 変えたいルール（クロスコンパイル、デプロイ、ログ追加のどれか）と、変えたい設定項目を伝えます。
4. plugin-creator が、対象の機器に合わせたスキルと、それに合わせた設定画面の項目を作り直します。
5. 作り直した後は、Copilot CLI を `/restart` するか、新しいセッション（`/clear`）で反映します。

## 2. SKILL.md を直接書き換える（ルールだけ変えるとき）

設定画面の項目を変えず、ルールの中身だけを変えるときは、SKILL.md を直接書き換えるだけで済みます。

1. 変えたいスキルの SKILL.md（例：`skills/cross-compile-rules/SKILL.md`）を開きます。
2. 「ここを機器に合わせて書く」の欄に、対象の機器の情報を書きます。
3. 欄の書き方は、ルールの本文の例（Makefile、バッチファイル、複数段階ビルド、TFTP、CRC など）を参考にします。これらは例であり、固定の仕様ではありません。
4. 保存したら、Copilot CLI を `/restart` するか、新しいセッションで反映します。

設定画面の項目（機器の IP アドレス、クロスコンパイルの情報など）は、SKILL.md の書き換えでは変わりません。項目を増やしたり減らしたりするときは、1の作り直しを使います。
