# デプロイのルール（実機のログの取り方を含む）

このルールは、embedded-debug-loop のビルド・デプロイ担当が、実機へデプロイし、ログを取るときに従う（K-07）。デプロイとログ取得の決まりは、ここに書かれた内容で決まる。

- 転送の後に、実機で行うこと（例：ファイルの置き換え、再起動）：

## 実機のシェルコンソールからのログの取り方

- 実機への接続方法（例：シリアル、telnet、ssh）と、ログインの方法：

- ログを取る時間や、取り終わりの目印：
- 取れたログの確かめ方（例：ログに出るはずの文字）：

## 例について

TFTP、CRC やサム値の調整、複数段階ビルドなどは例であり、固定の仕様ではない（K-07）。機器ごとに異なる処理は、この欄に書いたルールで決まる。

## 守ること

- デプロイできない、実機が応答しない、ログが取れない、のどれかが起きたら、そのまま進めず、起きたことを返す（K-15）。
- 実機のログは、作業フォルダの決まった場所に保存する。
