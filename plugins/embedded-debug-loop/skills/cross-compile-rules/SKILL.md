# クロスコンパイルのルール

このルールは、embedded-debug-loop のビルド・デプロイ担当が、ビルドするときに従う（K-07）。ビルドの決まりは、ここに書かれた内容で決まる。

## ここを機器に合わせて書く

- ツールチェーンや環境設定のファイルの場所：
- ビルドのコマンド（作業フォルダや引数を含む）：
- 成果物（ビルドで出来たファイル）の場所：
- ビルドが失敗したときに、見るべき出力：

## 例について

Makefile、バッチファイル、複数段階ビルド（複数の段階で作るビルド）は例であり、固定の仕様ではない（K-07）。機器の環境に合わせて、上の欄に書く。

## 守ること

- ビルドが失敗したら、そのまま進めず、失敗の出力を添えて返す（K-15）。
- ソースコードは変えない。
